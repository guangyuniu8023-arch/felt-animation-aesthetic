# 毛毡定格动画提示词模板

## 使用方式

只选择与任务匹配的模板，替换花括号变量。用户没有提供的技术规格保持未指定，不自行补成固定值。系列图或多镜头先填写“全局连续性块”，再写每项差异。

## 内置参考配置

用户没有另给风格参考时，默认采用 `cinematic_felt_miniature`：以 `assets/reference-01.jpg` 至 `assets/reference-06.jpg` 的共同特征约束材质、微缩摄影、景深和照明。只继承风格，不复刻其中的角色、品牌、文字、水印、车辆或具体剧情。


## 快速自检

- 提示词是否把对象重新构造成毛毡，而非只加表面滤镜？
- 是否说明参考图各自职责、保留项和允许改变项？
- 是否锁定纤维尺度、接缝、服装层数和关键道具？
- 视频是否包含起始状态、完整动作、环境反馈、镜头运动和结束状态？
- 是否只继承用户明确的输出规格，没有补写固定参数？
